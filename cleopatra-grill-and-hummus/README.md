# Cleopatra Grill and Hummus — Demo Website

**Live demo:** https://snowyiceberg.github.io/Inkscribe-web/cleopatra-grill-and-hummus/

A demo concept website for Cleopatra Grill and Hummus (10250 Federal Blvd, Unit 300, Federal Heights, CO 80260), built by Inkscribe. Six pages in one site — Home, Menu, Order Online, Reviews, About Us, Visit Us — with the real menu and prices, delivery links (DoorDash, Caviar, Uber Eats, Seamless, Grubhub, Postmates), photos, and guest reviews.

## Files

- `index.html` — the whole site. All six pages live in this one file and switch when you click the nav.
- `assets/` — food and restaurant photos, the logo, and the map files.

## Editing

The code is commented throughout. Search for `EDIT:` in `index.html` to jump to the spots you'll change most: menu items and prices, hours, phone number, photos, reviews, and delivery links.

This is a demo concept, not the restaurant's live site.
